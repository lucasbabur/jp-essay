jp-essay

A Claude Code skill that makes a model write an essay the slow way, and a script that checks it didn't cheat.

Question, reading, outline, bad draft, outline from memory, reorder, rewrite, fact-check, ask again.

The problem

Ask a student for an essay and the trouble is that they skip the work: no question, no reading, no outline, one draft. Ask a model and you get the opposite trouble. It does every step in seconds and still hands back the same essay everyone gets: no claim worth arguing, no specifics, inflated words, verdicts hedged into nothing, and a last paragraph that repeats the first.

jp-essay keeps the steps of Jordan B. Peterson's writing guide and aims each one at how models fail. A model can't forget its own draft, so a fresh reader outlines it from memory. Polished prose makes claims feel truer than they are, so a separate fact-checker checks every number and quote against the notes and changes nothing else. And no model grades the prose, because models asked to judge writing barely beat chance.

How a run goes

You fill in one short form. After that the skill runs on its own until the essay is finished.

  1. Question.One question a reader could answer two ways, and who that reader is.
  2. Reading list.A research agent gathers facts, scenes, numbers and verbatim quotes, asking what a skeptic, a newcomer and an expert would ask.
  3. Outline.A thesis, a case for the reader to follow, a puzzle for the ending to answer. A critic attacks it before any prose exists.
  4. Bad draft.Written straight through in a smart friend's voice, with at most one named study per paragraph.
  5. Outline from memory.A cold reader reads it once, outlines it from memory, and says where they would have stopped reading.
  6. Reorder.Structure gets fixed before any sentence gets polished.
  7. Rewrite.An editor marks the flawed spans. Each gets three different versions, and the good sentences stay as they are.
  8. Fact-check.Every claim is marked supported, fixed or cut against the notes.
  9. Can it be better?One more cold read, then it stops. Every further round of self-revision drifts.

Each step writes a file and passes a gate in check.py before the next one starts. The gates check what a script can check: length, structure, quotes that match the notes word for word, fact-check coverage, and a list of mechanical AI tells.

Install

You need Claude Code and uv.

npx jp-essay@latest

Start a new Claude Code session, then:

/jp-essay Why do we procrastinate on things we care about? 1200 en

Essays in English or Portuguese, 500 words and up; the length you give is a ceiling. /jp-essay-scientific runs the same process with sources, in-text citations and a reference list (APA, ABNT and others). Each essay and its working files land in ~/Documents/essays/<slug>/.
